# 🧠 Assignment 1: Square a Number
## 📌 Overview

This assignment focuses on implementing a simple Python program that computes the square of a number.

Submissions are automatically evaluated using a **CI/CD-based grading system powered by GitHub Actions**.

---

## 🎯 Problem Statement

Write a program that:

* Accepts an integer as input
* Outputs the square of that number

---

## 📥 Example

**Input**

```
5
```

**Output**

```
25
```

## ⚙️ How It Works

This repository uses **GitHub Actions** to automatically evaluate submissions.

### 🔄 Workflow

1. Code is pushed to the repository
2. GitHub Actions workflow is triggered
3. Automated test cases are executed
4. Results are generated and displayed

---

| Input | Expected Output |
| ----- | --------------- |
